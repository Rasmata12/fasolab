# assets/models

Placez ici les fichiers de modèles 3D (.glb / .gltf) du bracelet capteur ou des
équipements de laboratoire, si vous souhaitez remplacer les visuels statiques du
composant `Gant3D` par un vrai rendu 3D interactif (par exemple avec
`@react-three/fiber`).

Aucun modèle 3D n'était fourni au moment de la génération de ce projet — le
composant `Gant3D` affiche donc actuellement les photos réelles du prototype
(`assets/images/capteur-bracelet.png` et `capteur-en-situation.png`).
